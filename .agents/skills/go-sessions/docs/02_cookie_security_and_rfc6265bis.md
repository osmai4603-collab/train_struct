# 02. أمان ملفات تعريف الارتباط ومعايير RFC 6265bis (`Cookie Security & RFC 6265bis`)

تُعد ملفات تعريف الارتباط (Cookies) القناة الأساسية لنقل معرف الجلسة بين المتصفح والخادم. يتناول هذا الدليل الضوابط والمعايير الصارمة لإعداد الكوكيز في Go وفقاً لمسودة المعيار الدولي **[RFC 6265bis](https://datatracker.ietf.org/doc/html/draft-ietf-httpbis-rfc6265bis)** ومواصفة **[W3C CHIPS](https://github.com/privacycg/CHIPS)**.

---

## 1. محددات أمان الكوكي الإلزامية

```text
┌────────────────────────────────────────────────────────────────────────┐
│                     المحددات الأمنية الإلزامية للكوكي                  │
├───────────────────┬───────────────────┬────────────────────────────────┤
│ الخاصية           │ القيمة الإلزامية  │ الوظيفة الأمنية                │
├───────────────────┼───────────────────┼────────────────────────────────┤
│ HttpOnly          │ true              │ منع جافاسكريبت المتصفح من قراءة│
│                   │                   │ الكوكي؛ إحباط هجمات XSS        │
├───────────────────┼───────────────────┼────────────────────────────────┤
│ Secure            │ true              │ اشتراط الإرسال عبر قنوات HTTPS │
│                   │                   │ المشفرة حصراً (TLS)            │
├───────────────────┼───────────────────┼────────────────────────────────┤
│ SameSite          │ Lax أو Strict     │ منع المتصفح من إرسال الكوكي في │
│                   │                   │ الطلبات العابرة للمواقع (CSRF) │

├───────────────────┼───────────────────┼────────────────────────────────┤
```

## 2. البوادئ الأمنية الإلزامية: `__Host-` و `__Secure-`

تفرض المتصفحات الحديثة قيوداً صارمة لمنع التلاعب بالكوكيز بين النطاقات الرئيسية والفرعية (Cookie Tossing Attack):

### 2.1 البادئة الذهبية: `__Host-`
تُعد الحصن المنيع الموصى به لجلسات الويب. متطلبات المتصفح لقبولها:
1. أن تكون السمة `Secure` مفعلة (`true`).
2. أن يتم إرسالها واستقبالها عبر اتصال مشفر `HTTPS` فقط.
3. أن يكون المسار محدداً بالجذر (`Path=/`).
4. **حظر تحديد النطاق (No `Domain` attribute):** هذا يضمن ارتباط الكوكي بالنطاق الدقيق (`app.example.com`) ويمنع النطاقات الأخرى (`example.com` أو `hacked.example.com`) من قراءة أو كتابة الكوكي.

### 2.2 البادئة `__Secure-`
تتطلب `Secure=true` وعبر `HTTPS`، ولكنها تسمح بتحديد النطاق لمشاركته مع النطاقات الفرعية.

## 3. سياسة `SameSite` وأبعادها الدفاعية

- **`SameSite=StrictMode`:** يمنع إرسال الكوكي في أي طلب قادم من موقع خارجي، حتى لو نقر المستخدم على رابط عادي يؤدي إلى موقعك. (مثالي للتطبيقات فائقة الحساسية كالبنوك).
- **`SameSite=LaxMode`:** يسمح بإرسال الكوكي فقط في طلبات التنقل من المستوى الأعلى التي تستخدم أفعالاً آمنة (مثل النقر على رابط عبر `GET`)، بينما يحجبه في طلبات الـ POST والنماذج العابرة للمواقع. (هو الخيار المتوازن الأكثر انتشاراً).
- **`SameSite=NoneMode`:** يرسل الكوكي دائماً حتى في السياقات الخارجية. يتطلب إلزامياً `Secure=true`. **محظور استخدامه لجلسات المصادقة الأساسية.**

## 4. دعم W3C CHIPS وخاصية `Partitioned` في Go 1.23+

بدءاً من إصدار **Go 1.23**، أُضيفت خاصية `Partitioned bool` إلى بنية `http.Cookie` في الحزمة القياسية `net/http`.

تتيح هذه الخاصية عزل ملف تعريف الارتباط بحسب الموقع الأعلى (Top-Level Site Partition Key)، وهي ضرورية عندما يُطلب تضمين التطبيق داخل `iframe` في موقع آخر دون التضحية بأمان الجلسة أو التعرض لسياسات حظر الـ Third-Party Cookies.

## 5. الكود النموذجي لإعداد الكوكي في Go

```go
package session

import (
	"net/http"
	"time"
)

// WriteSessionCookie يضبط ملف تعريف الارتباط وفق أعلى المعايير الدولية
func WriteSessionCookie(w http.ResponseWriter, cookieName string, rawToken string, ttl time.Duration, isSecure bool) {
	cookie := &http.Cookie{
		Name:        cookieName, // يُفضل دائماً: "__Host-sess"
		Value:       rawToken,
		Path:        "/",
		MaxAge:      int(ttl.Seconds()),
		Expires:     time.Now().Add(ttl),
		HttpOnly:    true,
		Secure:      isSecure,
		SameSite:    http.SameSiteLaxMode,
		Partitioned: false, // تعيينها إلى true إن كانت الجلسة معزولة ضمن CHIPS
	}
	http.SetCookie(w, cookie)
}

// ClearSessionCookie يمحو الكوكي فور تسجيل الخروج
func ClearSessionCookie(w http.ResponseWriter, cookieName string, isSecure bool) {
	cookie := &http.Cookie{
		Name:     cookieName,
		Value:    "",
		Path:     "/",
		MaxAge:   -1,
		Expires:  time.Unix(0, 0),
		HttpOnly: true,
		Secure:   isSecure,
		SameSite: http.SameSiteLaxMode,
	}
	http.SetCookie(w, cookie)
}
```
