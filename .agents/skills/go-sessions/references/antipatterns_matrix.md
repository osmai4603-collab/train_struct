# مصفوفة الأنماط المضادة في إدارة الجلسات (`Anti-Patterns Matrix`)

توثق هذه المصفوفة الأخطاء الشائعة والأنماط المضادة (Anti-Patterns) التي تقع فيها فرق التطوير عند بناء خوادم الجلسات في Go، مع توضيح حجم الكارثة الأمنية أو التشغيلية والبديل الهندسي الصحيح.

## 1. تفصيل الخطأ الثاني: تخزين الرموز الخام

إذا قمت بتخزين:

```redis
SET sess:a1b2c3d4e5f6... "{user_id: 101}"
```

حيث `a1b2c3...` هو نفس الرمز الموجود في المتصفح، فإن أي تسريب لنسخ Redis الاحتياطية سيمكن المهاجم من الدخول فوراً لحسابات جميع المستخدمين النشطين.

**التصحيح:**

```go
// احسب الهاش دائماً
hash := sha256.Sum256([]byte(rawToken))
tokenHash := hex.EncodeToString(hash[:])
// خزّن الهاش فقط في Redis
rdb.Set(ctx, "sess:"+tokenHash, payload, ttl)
```

---

## 2. تفصيل الخطأ السادس: إغراق الذاكرة عند كل طلب

إذا كان لديك خدمة تتلقى 10,000 طلب بالثانية، وتستدعي `rdb.Set(ctx, key, val, ttl)` في كل طلب، فإنك تجبر Redis على استهلاك آلاف العمليات لمعالجة نقرات بسيطة في المتصفح.

**التصحيح:**
تطبيق **Write Throttling**:

- إذا كان `time.Since(sess.LastActiveAt) < 1 * time.Minute`، تجاوز استدعاء Redis واستمر في معالجة طلب الـ HTTP مباشرة.
