# 03. ميكانيكا التغليف، الفحص، و errors.Join (Wrapping, Inspection & Join)

> **الهدف:** إتقان ميكانيكا التغليف في Go، واستيعاب الفرق بين `%w` و `%v`، واستخدام `errors.Is` و `errors.As` و `errors.Join`.

---

## متى نستخدم `%w` مقابل `%v`؟

التغليف بـ `%w` ينشئ عقداً عاماً (Public Contract) مع مستخدمي الحزمة:

```text
┌────────────────────────┬────────────────────────────────────────────────────────┐
│ المحدد في fmt.Errorf   │ التأثير البرمجي والاستخدام المعماري                   │
├────────────────────────┼────────────────────────────────────────────────────────┤
│ %w (Wrap)              │ يحفظ الخطأ الأصلي في السلسلة.                          │
│                        │ يسمح للمستدعي بفحصه عبر errors.Is و errors.As.          │
│                        │ يُستخدم عندما يكون الخطأ جزءاً من الواجهة المسموح كشفها. │
├────────────────────────┼────────────────────────────────────────────────────────┤
│ %v (Mask / Hide)       │ يحول الخطأ إلى نص فقط ويقطع سلسلة التغليف.            │
│                        │ يمنع المستدعي من فحص الخطأ الداخلي.                    │
│                        │ يُستخدم لإخفاء تفاصيل المحركات (مثل SQL أو Redis).      │
└────────────────────────┴────────────────────────────────────────────────────────┘
```

---

## الفحص المعياري: `errors.Is` بدلاً من `==`

```go
// ❌ غير آمن: يفشل إذا تم تغليف الخطأ بأي طبقة فرعية
if err == sql.ErrNoRows { ... }

// ✅ الأسلوب المعياري المعتمد: يتتبع شجرة وسلسلة التغليف بالكامل
if errors.Is(err, sql.ErrNoRows) { ... }
```

### استخراج الأنواع بواسطة `errors.As`

```go
// استخراج نوع الخطأ المخصص مع الحماية من Nil Pointer
var appErr *platformerr.Error
if errors.As(err, &appErr) {
    fmt.Printf("failed at operation: %s with code: %s\n", appErr.Op, appErr.Code)
}
```

## تجميع الأخطاء المتعددة: `errors.Join` (Go 1.20+)

تتيح دالة `errors.Join` تجميع عدة أخطاء في قيمة واحدة، وهو النمط القياسي لإغلاق الموارد المتعددة:

```go
func CloseAll(closers ...io.Closer) error {
    var errs []error
    for _, c := range closers {
        if err := c.Close(); err != nil {
            errs = append(errs, err)
        }
    }
    // إذا كانت كل القيم nil، تعيد nil تلقائياً
    return errors.Join(errs...)
}
```

### التوافق مع `errors.Is` و `errors.As`

الخطأ الناتج عن `errors.Join` ينفذ واجهة `Unwrap() []error`. لذلك، تقوم `errors.Is` و `errors.As` بالبحث في شجرة الأخطاء بالكامل!
