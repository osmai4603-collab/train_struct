# 06. المتجهات الهجومية والدفاع الأمني الصارم وفق معيار RFC 8725

## 1. هجوم الخلط التشفيري (Key Confusion Attack: HMAC vs RSA)

### كيف يعمل الهجوم؟
1. خادم المصادقة يعلن عن مفتاح RSA العام الموثوق به للتحقق من التواقيع.
2. يقوم المهاجم بإنشاء رمز وتغيير الخوارزمية في الرأس إلى `"alg": "HS256"`.
3. يوقع المهاجم الرمز باستخدام **المفتاح العام لخادم الـ RSA كأنه سر HMAC متناظر**!
4. إذا كان خادم Go ساذجاً ويعيد المفتاح دون التحقق من تطابق الخوارزمية، سيقوم بتشغيل دالة التحقق من HMAC باستخدام بايتات المفتاح العام، وسيتطابق التوقيع بنجاح ليحصل المهاجم على صلاحية Administrator!

### التحصين الصارم في Go:
- فرض `jwt.WithValidMethods([]string{"RS256", "PS256"})` في خيارات الـ Parser.
- التحقق الإلزامي من نوع الخوارزمية داخل `Keyfunc`:
  ```go
  if _, ok := token.Method.(*jwt.SigningMethodRSA); !ok {
      return nil, fmt.Errorf("unexpected signing algorithm: %v", token.Header["alg"])
  }
  ```

## 2. هجمات حقن معاملات الرأس (`kid` & `jku` Injection)

### 2.1 حقن مسار الملف (Directory Traversal)
- المهاجم يرسل: `"kid": "../../../dev/null"`.
- إذا كان الخادم يقرأ المفتاح من مسار القرص بناءً على `kid`، فسيقرأ ملفاً فارغاً (0 bytes)، وسيتم توقيع الرمز بسلسلة نصية فارغة!
- **الحل:** فحص `kid` بنمط تعبيري صارم (`^[a-zA-Z0-9_-]+$`)، أو استخدام خريطة ثابتة بالمفاتيح المتاحة وتجاهل مسارات الملفات.

### 2.2 تزوير رابط المفاتيح (`jku` Spoofing)
- المهاجم يرسل ترويسة `"jku": "https://attacker.com/jwks.json"`.
- إذا قام الخادم بتنزيل المفاتيح من الرابط المحدد في الرأس، سيثق بمفتاح المهاجم!
- **الحل:** **تجاهل ترويسات `jku` و `x5u` تماماً.** الروابط الموثوقة تُحدد حصراً داخل إعدادات الخادم الثابتة.

## 3. أمان ملفات الارتباط في المتصفحات: معيار `__Host-`

لتأمين ملفات الارتباط ضد هجمات التلاعب بالنطاقات الفرعية (Subdomain Takeover / Injection) وهجمات CSRF:

```go
cookie := &http.Cookie{
    Name:     "__Host-refresh-token",
    Value:    token,
    Path:     "/",
    HttpOnly: true,                  // حظر قراءة document.cookie في JavaScript
    Secure:   true,                  // لا يُرسل إلا عبر HTTPS
    SameSite: http.SameSiteStrictMode, // حماية كاملة ضد هجمات CSRF
}
```

بادئة `__Host-` تفرض قيوداً صارمة في محركات المتصفحات: ترفض المتصفحات حفظ الكوكي إذا أرسل عبر HTTP غير مشفر، أو إذا حُدد له نطاق فرعي، أو إذا كان المسار يختلف عن الجذر `/`.
