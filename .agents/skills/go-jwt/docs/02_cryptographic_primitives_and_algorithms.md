# 02. المفاضلة التشفيرية والخوارزميات في بيئات الإنتاج

## 1. جدول المقارنة الشامل للخوارزميات

| الخوارزمية (Alg) | عائلة التشفير | طول المفتاح | طول التوقيع | الأداء الحسابي (Go Bench) | المناعة ضد الهجمات | القرار الإنتاجي |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **HS256** | متناظر (HMAC-SHA256) | 256 bits | 32 bytes | فائق السرعة جداً (~1-2 µs) | آمن ولكن يتطلب مشاركة السر مع كل خادم | **للخدمات الأحادية المغلقة فقط** |
| **RS256** | غير متناظر (PKCS#1 v1.5) | 2048+ bits | 256 bytes | متوسط التوقيع، سريع التحقق | عرضة لثغرات Bleichenbacher في الحشو | **تجنبها في الأنظمة الحديثة** |
| **PS256** | غير متناظر (RSASSA-PSS) | 2048+ bits | 256 bytes | مماثل لـ RS256 | **محصن تشفيرياً وموصى به في RFC 8725** | **الخيار الأول إذا كان النظام ملزماً بـ RSA** |
| **ES256** | منحنيات إهليلجية (ECDSA) | 256 bits | 64 bytes | سريع، تواقيع مدمجة | يعتمد على عشوائية الـ Nonce (تكرار الـ Nonce يكشف المفتاح الخاص) | **ممتاز بشرط استخدام التوقيع الحتمي RFC 6979** |
| **EdDSA (Ed25519)** | منحنيات إدواردز (Edwards) | 256 bits (32B) | 64 bytes | **أسرع خوارزمية غير متناظرة على الإطلاق** | **توقيع حتمي تلقائياً ومناعة تامة ضد هجمات القنوات الجانبية (Side-channel)** | **المعيار الذهبي الحديث الموصى به عالمياً لـ Go** |

## 2. تفوق Ed25519 الهندسي في لغة Go

تُعد خوارزمية `Ed25519` (عبر الحزمة الرسمية `crypto/ed25519` في Go) الخيار الأمثل للمشاريع الكبيرة للأسباب التالية:

1. **التوقيع الحتمي (Deterministic Signing):**
   على عكس ECDSA، لا تستخدم خوارزمية Ed25519 مولد أرقام عشوائية أثناء التوقيع، بل تشتق معامل التوقيع عبر تجزئة SHA-512 للمفتاح الخاص والحمولة. هذا يلغي تماماً الخطر الكارثي لتسريب المفتاح الخاص الناتج عن ضعف جودة مولد الأرقام العشوائية في النظام المضيف.
2. **العمليات الثابتة زمنياً (Constant-Time Operations):**
   تم تصميم العمليات الحسابية لمنحنى Curve25519 لتستغرق نفس عدد دورات المعالج بدقة، بغض النظر عن قيم البايتات للمفتاح. هذا يحصن الخادم ضد هجمات قياس التوقيت عبر الذاكرة المخبأة (Cache-timing Attacks).
3. **التوفير الضخم في استهلاك الباندويث والذاكرة:**
   المفتاح العام لا يتجاوز 32 بايت، والتوقيع 64 بايت فقط. عند مقارنتها بـ RSA-2048 (حيث التوقيع 256 بايت) في نظام يعالج مليارات الطلبات شهرياً، يوفر استخدام Ed25519 عشرات التيرابايت من حركة المرور عبر الشبكة.

## 3. معايير تشفير JWE في Go

عند الحاجة للسرية التامة (JWE)، يتم المزج بين خوارزميتين:

1. **خوارزمية إدارة المفاتيح (Key Management Algorithm - `alg`):**
   - `RSA-OAEP-256`: تشفير المفتاح المتماثل باستخدام RSA مع حشو OAEP وتجزئة SHA-256.
   - `ECDH-ES + A256KW`: تبادل المفاتيح عبر المنحنيات الإهليلجية وتغليف المفتاح بـ AES-256 Key Wrap (الموصى به لتقليل الحمل الحسابي).
2. **خوارزمية تشفير المحتوى (Content Encryption Algorithm - `enc`):**
   - `A256GCM` (AES-256 Galois/Counter Mode): التشفير الموثق القياسي عالمياً مع تسريع عتادي مباشر (Hardware AES-NI) في معالجات Intel و AMD و ARM64.
   - `ChaCha20-Poly1305`: بديل ممتاز فائق السرعة على الأجهزة التي تفتقر لتسريع AES العتادي.
