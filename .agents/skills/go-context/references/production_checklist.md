# قائمة مراجعة الجاهزية للإنتاج في مشاريع Go الكبيرة (Production Checklist)

استخدم هذه القائمة أثناء مراجعة الكود (Code Review) وقبل دمج أو نشر أي خدمة في بيئات الإنتاج:

---

## 1. تصميم الدوال والواجهات (API Contracts)
- [ ] هل كل دالة تنفذ عمليات شبكة أو استعلامات قواعد بيانات أو معالجة تستغرق وقتاً تقبل `ctx context.Context` كأول معامل؟
- [ ] هل تم الامتناع التام عن تخزين `context.Context` كحقل داخل أي `struct` في طبقات الخدمات والمستودعات؟
- [ ] هل تخلو شجرة الكود من تمرير `nil` كقيمة سياق وتم استبدالها بـ `context.Background()` أو `context.TODO()`؟
- [ ] هل كل دالة تقبل `context.Context` تُرجع `error` للسماح بإبلاغ المستدعي بحالات الإلغاء؟
- [ ] هل تخلو شروط `if` من أخطاء تظليل المتغيرات (`:=`) عند إنشاء سياق بمهلة زمنية مشروطة؟

---

## 2. إدارة الإلغاء والموارد (Cancellation & Leaks)
- [ ] هل يتبع كل استدعاء لـ `WithCancel` أو `WithTimeout` أو `WithDeadline` استدعاء مباشر لـ `defer cancel()`؟
- [ ] هل كل Goroutine غير متزامن أو حلقة عمل (Worker loop) يحتوي على `case <-ctx.Done():` للخروج النظيف الفوري؟
- [ ] هل قنوات الاتصال بين الـ Goroutines مبطنة (Buffered) بالشكل الكافي لمنع تعليق الكتابة في حال إلغاء المستمع؟
- [ ] هل تم استخدام `errgroup.WithContext` مع وضع سقف أعلى لعدد الـ Goroutines عبر `SetLimit` للعمليات المتوازية؟

---

## 3. سلامة وكفاءة بيانات السياق (Context Values)
- [ ] هل كافة مفاتيح `context.WithValue` مبنية على هياكل غير مصدّرة (`type contextKey struct{}`)؟
- [ ] هل تم الامتناع التام عن استخدام النصوص البدائية (`string`) أو الأرقام كمفاتيح؟
- [ ] هل تقتصر بيانات السياق على نطاق الطلب فقط (Trace ID, Request ID, User Claims) وخلوها من التبعيات أو كائنات قواعد البيانات؟
- [ ] هل تم استخدام نمط التجميع (Bundling) لحقن سمات الطلب في عقدة سياق واحدة وتفادي عمق شجرة البحث $O(N)$؟
- [ ] هل توجد دوال وصول آمنة نوعياً (`With...` و `FromContext`) تمنع الفرض اليدوي للأنواع (Type Assertions) داخل كود الأعمال؟

---

## 4. التكامل مع المنظومة والعمليات (Ecosystem & Operations)
- [ ] هل تُستخدم توابع `*Context` حصراً في كافة تعاملات `database/sql` (`QueryRowContext`, `ExecContext`, `BeginTx`)؟
- [ ] هل يتم إنشاء طلبات الـ HTTP للخدمات الخارجية عبر `http.NewRequestWithContext`؟
- [ ] هل تم فصل المهام الخلفية غير المتزامنة عن سياق الـ HTTP بواسطة `context.WithoutCancel(r.Context())` مع مهلة مستقلة؟
- [ ] هل يتم إيقاف الخوادم والخدمات بشكل سلس (Graceful Shutdown) عبر `signal.NotifyContext`؟
- [ ] هل تستفيد الاختبارات في Go 1.24+ من التابع المعياري المدمج `t.Context()` للتنظيف التلقائي للموارد؟
